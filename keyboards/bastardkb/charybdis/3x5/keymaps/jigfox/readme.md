# jigfox Charybdis Nano (3x5) keymap

Seven layers: Colemak-DH base with home row mods, QWERTY, extend, symbols,
numbers, functions (tri-layer of symbols and extend) and mouse (auto mouse layer).

Home row mods use QMK's Chordal Hold (`CHORDAL_HOLD`, handedness in
`chordal_hold_layout`), which replaced the Achordion module of the 2023 version.
`RGB_TOG` was renamed `RGB_TGL`, `KC_BTNx` is now `MS_BTNx`.
